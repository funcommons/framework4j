配置速查 ​

本页此前描述的「在线配置生成工具 config-tool.html」从未发布（v1.1.0 文档虚构，仓库中不存在该文件）， v1.10 文档评审时移除该描述。配置获取途径以下方真实入口为准。

配置获取途径 ​

1. 全模块配置参考（推荐） ​

配置参考 → —— 全模块配置键、默认值、说明速查表，随版本同步维护。

2. 模块文档 ​

每个模块文档（左侧「模块」导航）含各自的完整配置表与最小可运行示例：

场景入口
统一响应/错误码/trace 链路framework4j-web
鉴权（JWT + Refresh + 角色）framework4j-accesstoken
多数据源 + Druid（filters/wall 注意事项）framework4j-datasource
多 Redisframework4j-redis
分布式 ID / OpenIDframework4j-id
时间序列化 wire 契约framework4j-datetime
动态日志采集framework4j-tracelog

3. 最小可跑配置 ​

快速开始 含 JitPack/本地 install 双方式 + 最小 application.yml （含 v1.8 起 id/openid 显式启用说明）。
