核心设计原则 ​

  1. Lua 原子化 — 所有 Redis GET+SET 序列走 Lua（消除 TOCTOU）
  2. ThreadLocal 资源复用 — Mac / MessageDigest / Cipher 用 ThreadLocal
  3. 共享 Bean 单例 — 每模块抽共享 StringRedisTemplate
  4. 生产级安全深度 — 9 轮审计 + 8 轮新模块优化 = 145+ 项修复
