>
> **制定日期**：2026-07-04
> **最近更新**：2026-08-25（新增 framework4j-tracelog 模块，11 模块；架构图更新）

## 一、设计原则

1. **单一职责**：每个 Maven 模块只承担一个明确职责（api / id / datetime / redis / datasource / sql-tracing / accesstoken / idempotency / all）。
2. **可插拔**：所有模块通过 `@ConditionalOnProperty(prefix="framework4j.<module>", name="enabled")` 开关，默认按需启用。
3. **顶级 BeanPostProcessor**：`@RedisOn` / `@DataSourceOn` / `@RequiresToken` 处理器必须是顶级类（非内嵌静态类），避免 Spring BeanPostProcessor 加载顺序警告。
4. **Jackson 统一**：禁 fastjson2、禁 commons-lang3 StringUtils（用 Spring 的）、禁 commons-codec HmacUtils（用 JDK `javax.crypto.Mac` + ThreadLocal 缓存）。
5. **配置前缀**：所有 `@ConfigurationProperties` 走 `framework4j.<module>.*` 前缀；accesstoken 用 kebab-case `framework4j.access-token.*`。
6. **包名约定**：`fun.commons.framework4j.<module>`，与目录名对齐。仅 accesstoken 用 `fun.commons.framework4j.accesstoken`（历史）。

## 五、命名约定

| 类别 | 约定 | 示例 |
|---|---|---|
| 模块目录 | `framework4j-<module>` | `framework4j-api`、`framework4j-accesstoken` |
| artifactId | 同目录名 | `framework4j-api` |
| 包名 | `fun.commons.framework4j.<module>` | `fun.commons.framework4j.redis` |
| 配置前缀 | `framework4j.<module>.*` | `framework4j.access-token.*`（kebab-case） |
| AutoConfiguration | `<Module>AutoConfiguration` | `MultiRedisAutoConfiguration` |
| Properties | `<Module>Properties` | `AccessTokenProperties` |
| BeanPostProcessor | 顶级类 `<Annotation>BeanPostProcessor` | `RedisOnBeanPostProcessor` |
| 注解 | `@<Action>On` | `@RedisOn`、`@DataSourceOn`、`@RequiresToken` |
| 工具类 | `<Domain>Utils` | `TokenUtils`、`TokenKeyBuilder` |
| 测试目录 | `src/test/java/.../<module>/` 分 `unit/`、`functional/`、`integration/`、`performance/` | — |

## 六、关键演进（v1.x → v2.0）

| 演进项 | v1.x | v2.0 | 收益 |
|---|---|---|---|
| core 模块职责 | 3741 行，混合 api/id/openid/datetime | 998 行 → 拆为 api + datetime + id 独立模块 | 单一职责，按需引入 |
| JSON 库 | fastjson2 + Jackson 混用 | Jackson 统一 | 消除 autotype RCE 风险 |
| BeanPostProcessor | 内嵌静态类 | 顶级类 | 消除 Spring 加载警告 |
| accesstoken refresh | AccessTokenGenerator 单类含 refresh | 拆 AccessTokenGenerator + RefreshTokenService + TokenKeyBuilder | 单类 < 200 行 |
| TokenInterceptor | 1 类 254 行 | TokenInterceptor 路由 + AccessToken/RefreshValidationStrategy | 策略模式可扩展 |
| sql-tracing | 内嵌于 datasource | 独立模块 + 自己的 AutoConfiguration | 可单独引入 |
| Redis Key 构造 | 散落在 4 个类中字符串拼接 | TokenKeyBuilder 集中 5 类 | 一致性 |
| HMAC 签名 | commons-codec HmacUtils | JDK `javax.crypto.Mac` + ThreadLocal 缓存 | 减依赖 + 性能 |
| 拦截器路径 | 硬编码 `/**` | `pathPatterns` / `excludePathPatterns` 可配置 | 灵活 |

## 七、不在 v2.0 范围

- **JJWT 迁移**：当前 TokenUtils 自实现 HS256，未引入 JJWT。评估：JJWT 提供 RS256/ES256 但增依赖。v2.0 保留自实现。
- **Spring Security 集成**：TokenContext → SecurityContextHolder 桥接由消费者应用负责。
- **OAuth2 第三方登录**：微信/钉钉/GitHub 由消费者应用自实现。
- **审计日志表**：append-only + hash chain 由消费者应用负责。
- **PostgreSQL 专用功能**：framework4j-datasource 仅做 Druid + MyBatis Plus 抽象，不绑特定数据库。
